# Formación → Picasso

Cada curso o lección que hace Juan se resume aquí en **reglas aplicables a Picasso**. Cada regla lleva la mejora que provoca y la sección del documento maestro que toca. No se copian transcripciones: se extrae criterio.

Así el aprendizaje queda en la máquina: alimenta las opciones de dirección, las plantillas de prompt, el catálogo de modelos y, cuando sea real, el criterio del asistente (§10).
